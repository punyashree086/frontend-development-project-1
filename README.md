# Frontend Development – Project 1

## Static Portfolio Website

This project is a personal portfolio website created as part of the
DecodeLabs Frontend Development – Project 1.

The main objective of this project is to demonstrate the fundamentals
of HTML and CSS by creating a clean, structured, and readable static webpage.

## 🚀 Technologies Used

- HTML5
- CSS3

## 📌 Features

- Responsive navigation bar
- Home section
- About Me section
- Skills section
- Projects section
- Contact section
- Profile image
- Responsive layout
- Clean and modern design
